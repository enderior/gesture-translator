# Модуль перевода языка жестов в текст

> ⚠️ **Дисклеймер:** Проект разработан в образовательных целях в рамках междисциплинарного проекта. Модуль не является медицинским или профессиональным инструментом перевода и не заменяет услуги квалифицированных переводчиков русского жестового языка (РЖЯ).

Программный модуль для цифровых коммуникационных сервисов: принимает видео с жестами русского жестового языка (РЖЯ), распознаёт последовательность жестов и переводит её в естественный русский текст.

## Как это работает

```text
[Браузерное расширение]
        │  пользователь загружает видео
        ▼
[FastAPI backend]
   1. Валидация и нарезка видео на кадры (OpenCV)
   2. Извлечение скелета рук/позы (MediaPipe)
   3. Модель распознавания → последовательность глоссов (gloss-строка)
   4. LLM (GigaChat API) → грамотный русский текст
        │
        ▼
[Расширение выводит текст на страницу и в консоль браузера]
```

_(Интеграция с мессенджерами, например VK, запланирована на следующих этапах)._

## Быстрый старт (Бэкенд)

1. Убедитесь, что у вас установлен Python 3.11 (рекомендуется использовать [uv](https://github.com/astral-sh/uv)).
2. Перейдите в папку бэкенда:
    ```bash
    cd backend
    ```
3. Создайте виртуальное окружение и активируйте его:
    ```bash
    # С использованием uv (рекомендуется)
    uv venv --python 3.11
    .\.venv\Scripts\Activate.ps1  # Windows (PowerShell)
    # source .venv/bin/activate   # Linux/macOS
    ```
4. Установите зависимости:
    ```bash
    uv pip install -r requirements.txt
    ```
5. Запустите сервер:
    ```bash
    uvicorn app.main:app --reload --port 8000
    ```
    Открыть Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)

## Быстрый старт (Расширение)

### Для Chrome / Yandex / Edge

1. Откройте `chrome://extensions/` (или `browser://extensions/` для Яндекса).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
   _(Используется файл `extension/manifest.json`)_

### Для Firefox

1. Откройте новую вкладку и введите `about:debugging`.
2. Нажмите «This Firefox» (Этот Firefox) слева.
3. Нажмите «Load Temporary Add-on...» (Загрузить временное дополнение).
4. Выберите файл `extension/manifest.firefox.json`.

### Как пользоваться

1. Убедитесь, что бэкенд запущен (см. выше).
2. Нажмите на иконку расширения в панели браузера (откроется новая вкладка).
3. Выберите любой файл (видео или картинку) и нажмите «Отправить на обработку».
4. Результат появится на странице и в консоли браузера (F12).
