# Модуль перевода языка жестов в текст

> ⚠️ **Дисклеймер:** Проект разработан в образовательных целях в рамках междисциплинарного проекта. Модуль не является медицинским или профессиональным инструментом перевода и не заменяет услуги квалифицированных переводчиков русского жестового языка (РЖЯ).

Программный модуль для цифровых коммуникационных сервисов: принимает видео с жестами русского жестового языка (РЖЯ), распознаёт последовательность жестов и переводит её в естественный русский текст, который вставляется в поле ввода мессенджера через браузерное расширение.

## Как это работает

```text
[Браузерное расширение (VK)]
        │  пользователь загружает видео
        ▼
[FastAPI backend]
   1. Валидация и нарезка видео на кадры (OpenCV)
   2. Извлечение скелета рук/позы (MediaPipe)
   3. Модель распознавания → последовательность глоссов (gloss-строка)
   4. LLM (GigaChat API / локальная Qwen) → грамотный русский текст
        │
        ▼
[Расширение вставляет текст в поле сообщения VK]
```

## Стек

| Слой       | Технологии                                                               |
| :--------- | :----------------------------------------------------------------------- |
| Бэкенд     | Python 3.11, FastAPI, Uvicorn, Pydantic                                  |
| CV         | MediaPipe, OpenCV                                                        |
| ML         | PyTorch, LSTM/GRU/Transformer                                            |
| LLM        | GigaChat API (основной), Qwen 2.5/3.5 7–9B 4-bit через Ollama (fallback) |
| Расширение | Chrome Manifest V3, JS, Content Script, MutationObserver                 |
| Данные     | Slovo (РЖЯ), готовые MediaPipe-аннотации                                 |
| Тесты      | pytest                                                                   |

## Быстрый старт (бэкенд)

```bash
cd backend
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Открыть Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)

## Быстрый старт (расширение)

1. Открыть `chrome://extensions/`
2. Включить «Режим разработчика»
3. «Загрузить распакованное расширение» → выбрать папку `extension/`
4. Открыть `vk.com`, залогиниться, нажать на иконку расширения
