## 1. Общие сведения

**Наименование:** модуль перевода русского жестового языка (РЖЯ) в текст
для цифровых коммуникационных сервисов.

**Основание:** междисциплинарный проект, 2 курс, [направление/группа].

**Сроки:** [дата начала] — [дата защиты].

---

## 2. Назначение и цель

Модуль предназначен для людей с нарушениями слуха и речи, а также для
ситуаций, когда голосовой ввод недоступен. Пользователь записывает или
загружает короткое видео с жестами; модуль распознаёт последовательность
жестов, переводит её в грамотный русский текст и вставляет результат
в поле ввода мессенджера.

**Цель проекта:** создать работающий прототип, демонстрирующий сквозной
пайплайн «видео → жест → глосс → текст → мессенджер» на ограниченном
словаре жестов.

---

## 3. Термины и сокращения

| Термин                        | Определение                                                                                                                               |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Жест**                      | Изолированный жест РЖЯ, соответствующий одному смыслу/слову                                                                               |
| **Глосс**                     | Условная текстовая запись жеста (например, `ХОТЕТЬ`, `ЕСТЬ`)                                                                              |
| **Gloss-строка (FEN-строка)** | Последовательность глоссов, промежуточное представление между жестом и текстом. `[УТОЧНИТЬ: что именно наставник называет «FEN-строкой»]` |
| **Лендмарки**                 | Координаты ключевых точек скелета руки/позы, извлекаемые MediaPipe                                                                        |
| **РЖЯ**                       | Русский жестовый язык                                                                                                                     |
| **LLM**                       | Большая языковая модель, переводит глоссы в естественный текст                                                                            |

## 4. Функциональные требования

### 4.1. Ввод

- FR-1. Пользователь загружает видеофайл (`.mp4`, `.webm`, `.mov`).
- FR-2. Допустимая длительность — до 30 секунд. `[УТОЧНИТЬ]`
- FR-3. Допустимый размер — до 50 МБ. `[УТОЧНИТЬ]`
- FR-4. Видео должно содержать одного человека, руки в кадре.

### 4.2. Обработка

- FR-5. Бэкенд принимает видео, создаёт задачу с `job_id`.
- FR-6. Видео нарезается на кадры, из каждого извлекаются лендмарки (MediaPipe).
- FR-7. Модель распознавания классифицирует последовательность лендмарков в последовательность глоссов.
- FR-8. Gloss-строка передаётся в LLM для перевода в естественный русский текст.
- FR-9. Результат сохраняется и доступен по `job_id`.

### 4.3. Вывод

- FR-10. API отдаёт распознанные глоссы, финальный текст и статус обработки.
- FR-11. Браузерное расширение показывает результат пользователю.
- FR-12. По нажатию кнопки текст вставляется в активное поле ввода VK.

### 4.4. Словарь жестов (MVP)

- FR-13. Минимальный словарь — **не менее 5 жестовых групп**.
- FR-14. Для каждой группы — набор глоссов и соответствующий сценарий (см. п. 6).
- FR-15. Расширение словаря — за счёт дообучения модели на новых данных.

## 7. Архитектура

```text
[Chrome Extension (VK)]
     │  HTTPS
     ▼
[FastAPI backend]
  ├─ POST /api/jobs          — загрузка видео
  ├─ GET  /api/jobs/{id}     — статус и результат
  └─ GET  /api/health        — проверка
     │
     ├─ services/video.py       — валидация, нарезка кадров
     ├─ services/landmarks.py   — MediaPipe → лендмарки
     ├─ services/recognizer.py  — модель → gloss-строка
     └─ services/translator.py  — LLM → русский текст
```

### 7.1. Формат «gloss-строки» (черновик)

```json
{
    "glosses": ["Я", "ХОТЕТЬ", "ЕСТЬ"],
    "confidence": [0.95, 0.88, 0.91]
}
```

`[УТОЧНИТЬ: формат FEN-строки у наставника]`

### 7.2. LLM-слой

- **Основной бэкенд:** GigaChat API (бесплатный лимит для физлиц).
- **Fallback:** локальная Qwen 2.5/3.5 7–9B (4-bit, Ollama) на ноутбуке разработчика.
- Интерфейс: `translate(glosses: list[str], scenario: str) -> str`.
