# Техническое задание

## Модуль перевода языка жестов в текст для цифровых коммуникационных сервисов

Версия: 1.0
Статус: Согласовано с наставником

---

## 1. Общие сведения

**Наименование:** модуль перевода русского жестового языка (РЖЯ) в текст для цифровых коммуникационных сервисов.
**Наставник:** Данильченко В.И., к.т.н., доцент каф. САПР им. В.М. Курейчика.

---

## 2. Назначение и цель

Модуль предназначен для людей с нарушениями слуха и речи. Пользователь загружает короткое видео с жестами; модуль распознаёт последовательность жестов, переводит её в грамотный русский текст.
**Цель проекта:** создать работающий прототип, демонстрирующий сквозной пайплайн «видео → жест → глосс → текст».

---

## 3. Термины и сокращения

| Термин           | Определение                                                                                                          |
| :--------------- | :------------------------------------------------------------------------------------------------------------------- |
| **Жест**         | Изолированный жест РЖЯ, соответствующий одному смыслу/слову                                                          |
| **Глосс**        | Условная текстовая запись жеста (например, `ХОТЕТЬ`, `ЕСТЬ`)                                                         |
| **Gloss-строка** | Последовательность глоссов, промежуточное представление между жестом и текстом (например, `["Я", "ХОТЕТЬ", "ЕСТЬ"]`) |
| **Лендмарки**    | Координаты ключевых точек скелета руки/позы, извлекаемые MediaPipe                                                   |
| **РЖЯ**          | Русский жестовый язык                                                                                                |

---

## 4. Функциональные требования

### 4.1. Ввод

- FR-1. Пользователь загружает видеофайл (`.mp4`, `.webm`, `.mov`).
- FR-2. Допустимая длительность — до 30 секунд. Допустимый размер — до 50 МБ.
- FR-3. Видео должно содержать одного человека, руки в кадре.

### 4.2. Обработка

- FR-4. Бэкенд принимает видео, создаёт задачу с `job_id`.
- FR-5. Видео нарезается на кадры, из каждого извлекаются лендмарки (MediaPipe).
- FR-6. Модель распознавания классифицирует последовательность лендмарков в Gloss-строку.
- FR-7. Gloss-строка передаётся в LLM (GigaChat API) для перевода в естественный текст.
- FR-8. Результат сохраняется и доступен по `job_id`.

### 4.3. Вывод

- FR-9. API отдаёт распознанные глоссы, финальный текст и статус обработки.
- FR-10. Браузерное расширение выводит результат на страницу и в консоль браузера (для этапа MVP).
- FR-11. _(В перспективе)_ Интеграция с мессенджером VK.

### 4.4. Словарь жестов и Сценарии

- FR-12. Минимальный словарь — **не менее 5 жестовых групп**.
- FR-13. Сценарии использования — на выбор команды (приветствие, экстренная помощь, бытовые просьбы и т.д.).

---

## 5. Нефункциональные требования

- NFR-1. Время обработки видео до 10 секунд — не более 30 секунд.
- NFR-2. Бэкенд разворачивается локально.
- NFR-3. Расширение — Chrome/Edge/Yandex (Manifest V3) и Firefox.
- NFR-4. Персональные данные не хранятся: видео удаляется после обработки.
- NFR-5. Код — Python 3.11, JS.

---

## 6. Архитектура и LLM-слой

```text
[Браузерное расширение] (Chrome/Yandex/Firefox)
     │  HTTPS
     ▼
[FastAPI backend]
  ├─ POST /api/jobs          — загрузка видео
  ├─ GET  /api/jobs/{id}     — статус и результат
  └─ GET  /api/health        — проверка
     │
     ├─ services/video.py       — валидация, нарезка кадров
     ├─ services/landmarks.py   — MediaPipe → лендмарки
     ├─ services/recognizer.py  — модель → gloss-строка
     └─ services/translator.py  — GigaChat API → русский текст
```

- **LLM:** GigaChat API (основной вариант).
- **Интерфейс:** `translate(glosses: list[str], scenario: str) -> str`.

---

## 7. Критерии приёмки

- CA-1. Пользователь загружает видео и получает текст в интерфейсе расширения.
- CA-2. Работают **все выбранные сценарии** (минимум 7).
- CA-3. Распознаётся **не менее 5 жестовых групп**.
- CA-4. Gloss-строка корректно переводится LLM в грамотный русский.
- CA-5. Есть демонстрационное видео с оригинальной озвучкой.
- CA-6. Репозиторий воспроизводим (requirements, инструкция).
